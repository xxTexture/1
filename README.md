# 🤖 Discord Bot — Полная документация

## 📁 Структура проекта

```
discord_bot/
├── main.py                  # Точка входа, запуск бота
├── config.py                # Технические настройки (токены, ID каналов, ролей, кулдауны)
├── texts.py                 # ✏️ ВСЕ ТЕКСТЫ БОТА (меняются из Discord: /тексты)
├── database.py              # JSON-хранилище данных (кулдауны, авто-ответы и т.д.)
├── requirements.txt         # Зависимости
├── data.json                # Создаётся автоматически при первом запуске
│
├── utils/
│   ├── helpers.py           # Вспомогательные функции (транскрипты, парсинг времени)
│   ├── checks.py            # Система проверки прав доступа
│   ├── forms.py             # 📦 Хранилище типов тикетов и вопросов заявок
│   └── staff_tracker.py     # 📊 Модуль учёта действий и активности персонала
│
└── cogs/
    ├── tickets.py           # 📩 Система тикетов (динамические типы и формы)
    ├── applications.py      # 📋 Заявки в команду (настраиваемые анкеты)
    ├── forms_setup.py       # 🧰 Настройка форм: /тикет-настройка, /заявки-настройка
    ├── text_setup.py        # ✏️ Настройка текстов: /тексты
    ├── moderation.py        # 🔨 Модерация (mute/ban/kick + авто-разбан + варны)
    ├── auto_reply.py        # 🤖 Авто-ответ на сообщения игроков
    ├── donate.py            # 💳 Магазин доната (/dotane)
    ├── info_cmd.py          # ℹ️ Команда /info
    ├── ai_chat.py           # 🧠 ИИ чат (Anthropic Claude)
    ├── access_control.py    # 🔐 Управление доступом к командам
    ├── admin_utils.py       # 🛠️ Утилиты (/say, /say-dm, /ip)
    └── staff_stats.py       # 📊 Статистика, рейтинг и роли персонала
```

## ⚙️ Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка config.py

Открой `config.py` и заполни:

| Параметр | Описание |
|----------|----------|
| `TOKEN` | Токен бота с Discord Developer Portal |
| `AI_API_KEY` | Ключ Anthropic API (для ИИ чата, необязательно) |
| `ADMIN_ROLE_ID` | ID роли администратора |
| `SUPPORT_ROLE_ID` | ID роли поддержки |
| `TECH_SUPPORT_ROLE_ID` | ID роли тех-поддержки |
| `STAFF_PING_ROLES` | Список ID ролей, которых пинговать при заявке в персонал |
| `DS_ADMIN_PING_ROLES` | Список ID ролей для заявок в дс-адм |
| `BUILDER_PING_ROLES` | Список ID ролей для заявок в билдеры |
| `STAFF_SERVER_ROLES` | ID ролей персонала сервера (для статистики и рейтинга) |
| `STAFF_DISCORD_ROLES` | ID ролей персонала дискорда (для статистики и рейтинга) |
| `STAFF_BUILDER_ROLES` | ID ролей билдеров (для статистики и рейтинга) |
| `SUPPORT_PING_ROLES` | Список ID ролей для тикетов поддержки |
| `TECH_SUPPORT_PING_ROLES` | Список ID ролей для тикетов тех-поддержки |
| `REPORT_PLAYER_PING_ROLES` | Список ID ролей для жалоб на игроков |
| `REPORT_STAFF_PING_ROLES` | Список ID ролей для жалоб на персонал |
| `*_ESCALATE_ROLES` | Старшие роли для кнопки «Передать» в тикете (4 списка) |
| `LOG_CHANNEL_1_ID` | Главный канал логов |
| `LOG_CHANNEL_2_ID` | Второй канал логов |
| `APP_CH_STAFF` | Канал для заявок в персонал |
| `APP_CH_DS_ADMIN` | Канал для заявок в дс-адм |
| `APP_CH_BUILDER` | Канал для заявок в билдеры |
| `AI_CHANNEL_ID` | Канал для ИИ чата (или настраивается через /ии канал) |
| `TICKET_CATEGORY_ID` | Категория для тикетов по умолчанию (None = без категории) |
| `TICKET_COOLDOWN` | Кулдаун тикетов в секундах (по умолчанию 300 = 5 мин) |
| `APPLICATION_COOLDOWN` | Кулдаун заявок в секундах (по умолчанию 86400 = 24 ч) |
| `TICKET_COLOR` / `APP_COLOR` | Цвета панелей тикетов и заявок |
| `TICKET_BANNER` / `APP_BANNER` | Картинка-баннер ПАНЕЛЕЙ (внутри тикета/анкеты — свои, через `/тикет-настройка баннер` и `/заявки-настройка баннер`) |

> ✏️ Все тексты бота (панели, кнопки, сообщения) настраиваются через `/тексты`
> или в файле `texts.py` — в `config.py` остались только технические настройки.

### 3. Запуск
```bash
python main.py
```

## 📋 Список всех команд

### 📩 Тикеты
| Команда | Описание |
|---------|----------|
| `/setup-tickets` | Установить панель тикетов в канал (обновляется автоматически) |
| `/ticket add @игрок` | Добавить игрока в тикет |
| `/ticket remove @игрок` | Убрать игрока из тикета |
| `/ticket rename имя` | Переименовать канал тикета |
| `/ticket close` | Закрыть тикет с указанием причины |

**Типы тикетов по умолчанию:**
- 💬 **Помощь** — общие вопросы, помощь, баги (каналы `support-ник`)
- ⚙️ **Тех-поддержка** — технические проблемы (каналы `tech-support-ник`)
- 🚨 **Жалоба на игрока** — читы, оскорбления, гриферство (каналы `report-player-ник`)
- 🛡️ **Жалоба на персонал** — жалобы на сотрудников (каналы `report-staff-ник`)

**Возможности внутри тикета:**
- 🖼️ **Баннер** — картинка внизу первого embed тикета, своя для каждого типа
  (`/тикет-настройка баннер тип ссылка`)
- 📎 **Фото/видео** — игрок просто кидает файлы сообщением прямо в канал тикета
- 🔁 **Кнопка «Передать»** — если сотрудник не справился, нажимает её → старшая роль
  пингуется и получает доступ в канал. Роли: `/тикет-настройка передача ...`,
  текст кнопки и сообщения: `/тексты изменить TICKET_FORWARD_BTN ...`
- 🔒 **«Закрыть» и «Передать» — только для персонала** — игрок не может
  закрыть/передать свой тикет (текст отказа: `TICKET_STAFF_ONLY`)

> ⚠️ Названия каналов тикетов теперь латинские — Discord API не разрешает
> кириллицу в названиях текстовых каналов. Ники игроков транслитерируются
> автоматически (`Иван` → `ivan`).

> ⚠️ **Чтобы закрытый тикет удалялся**, у бота должно быть СЕРВЕРНОЕ право
> «Управление каналами» (или «Администратор»): *Настройки сервера → Роли →
> роль бота*. Права на самом канале тикета для этого не достаточно.
> Если удалить не выходит — бот скажет об этом прямо в тикете, а не «зависнет».

### 🧰 Настройка типов тикетов и форм — `/тикет-настройка`
Полностью настраиваемые типы обращений: у каждого своя форма (до 5 вопросов),
свои роли для пинга, своя категория каналов и цвет. Панели обновляются
автоматически — перезапуск бота не нужен.

| Команда | Описание |
|---------|----------|
| `/тикет-настройка список` | Все типы, их формы, роли и категории |
| `/тикет-настройка добавить код название ...` | Новый тип обращения (напр. `report`, «🚨 Жалоба») |
| `/тикет-настройка удалить код` | Удалить тип |
| `/тикет-настройка изменить код поле значение` | Название / описание / эмодзи / цвет / префикс |
| `/тикет-настройка категория код [#категория]` | Категория для каналов типа |
| `/тикет-настройка тест код` | 🧪 Открыть форму и посмотреть предпросмотр |
| `/тикет-настройка вопрос добавить код вопрос ...` | Добавить вопрос в форму (обязательность, размер поля, лимит символов) |
| `/тикет-настройка вопрос удалить код номер` | Удалить вопрос из формы |
| `/тикет-настройка роль добавить код @роль` | Роль для пинга при создании |
| `/тикет-настройка роль удалить код @роль` | Убрать роль из пинга |
| `/тикет-настройка роль очистить код` | Убрать все роли из пинга |
| `/тикет-настройка передача добавить код @роль` | 🔁 Старшая роль для кнопки «Передать» |
| `/тикет-настройка передача удалить код @роль` | Убрать роль из передачи |
| `/тикет-настройка передача очистить код` | Убрать все роли из передачи |
| `/тикет-настройка баннер код [ссылка]` | 🖼️ Баннер внутри тикета (без ссылки — убрать) |

**Пример — настроить готовый тип «Жалоба на игрока»:**
```
/тикет-настройка баннер код:жалоба-игрок ссылка:https://i.imgur.com/example.png
/тикет-настройка передача добавить код:жалоба-игрок роль:@Куратор
/тексты изменить TICKET_FORWARD_BTN 🔁 Передать куратору
```

### 📋 Заявки в команду
| Команда | Описание |
|---------|----------|
| `/setup-applications` | Установить панель заявок (обновляется автоматически) |
| `/заявки-настройка список` | Вопросы и настройки анкет по направлениям |
| `/заявки-настройка вопрос добавить направление вопрос ...` | Добавить вопрос в анкету (до 5) |
| `/заявки-настройка вопрос удалить направление номер` | Удалить вопрос анкеты |
| `/заявки-настройка баннер направление [ссылка]` | 🖼️ Баннер внутри анкеты (без ссылки — убрать) |

**Направления:** Персонал / ДС-Адм / Билдеры (каналы и пинги — в `config.py`)

**При отклонении:** модератор указывает причину → отображается в канале с заявкой
И отправляется в ЛС игроку.
**При принятии:** игроку приходит ЛС от бота. Тексты обоих сообщений настраиваются:
`/тексты изменить APP_ACCEPTED_DM_TITLE ...`, `APP_ACCEPTED_DM_DESC ...`,
`APP_REJECTED_DM_TITLE ...`, `APP_REJECTED_DM_DESC ...`

### ✏️ Настройка всех текстов — `/тексты`
Каждый текст бота (заголовки панелей, кнопки, сообщения, плейсхолдеры форм)
меняется прямо из Discord без перезапуска. Значения по умолчанию — в `texts.py`.

| Команда | Описание |
|---------|----------|
| `/тексты список [категория] [страница]` | Все тексты по категориям (🔶 = изменён) |
| `/тексты поиск фрагмент` | Найти текст по фразе («тикет», «жалоба»...) |
| `/тексты показать ключ` | Текущее значение + значение по умолчанию |
| `/тексты изменить ключ` | Окно редактирования с текущим текстом |
| `/тексты сброс [ключ]` | Вернуть текст (или все тексты) к дефолту |

**Пример:** `/тексты изменить TICKET_PANEL_TITLE` → вписать своё название панели →
панель обновится сразу. Плейсхолдеры вроде `{user}`, `{channel}` бот подставляет сам —
их нужно оставлять в тексте.

### 🔨 Модерация
| Команда | Описание |
|---------|----------|
| `/ds-panel @игрок` | Открыть интерактивную панель модерации (Mute, Ban, Kick, Unmute) |
| `/mute @игрок [срок] [причина]` | Выдать тайм-аут игроку (10m, 2h, 1d) |
| `/unmute @игрок [причина]` | Снять тайм-аут с игрока |
| `/ban @игрок [срок] [причина]` | Забанить игрока (срок с авто-разбаном или навсегда) |
| `/kick @игрок [причина]` | Кикнуть игрока с сервера |
| `/warn @игрок причина` | Выдать предупреждение игроку (сохраняется в БД + ЛС) |
| `/warns @игрок` | Посмотреть список предупреждений игрока |
| `/warn-снять @игрок [номер]` | Снять предупреждение с игрока |
| `/purge число [пользователь]` | Удалить до 1000 сообщений (bulk delete) |
| `/unban user_id [причина]` | Разбанить по ID |
| `/кд-сброс @игрок тип` | Сбросить кулдаун тикета/заявки |

**Формат времени:** `30s`, `10m`, `2h`, `7d`

### 📊 Статистика и рейтинг персонала
Автоматический учёт всех действий команды проекта: закрытые тикеты, выданные наказания (через бота и Discord), проверенные заявки, активное время в голосовых и текстовых каналах.

| Команда | Описание |
|---------|----------|
| `/персонал-статистика [сотрудник] [период]` | Личная карточка статистики сотрудника (за неделю / за всё время) |
| `/персонал-рейтинг [категория] [период] [сортировка]` | Таблица лидеров и рейтинг сотрудников с фильтрами |
| `/персонал-роли список` | Показать настроенные роли для каждой категории персонала |
| `/персонал-роли добавить категория роль` | Привязать роль к категории персонала |
| `/персонал-роли удалить категория роль` | Удалить роль из категории персонала |
| `/персонал-роли панель категория` | Интерактивное меню выбора ролей (Discord Role Picker) |
| `/персонал-роли сбросить` | Сбросить роли к дефолтным из `config.py` |
| `/персонал-сброс неделя` | Сбросить недельную статистику всех сотрудников |
| `/персонал-сброс сотрудник @игрок` | Полностью сбросить статистику конкретного сотрудника |
| `/персонал-сброс полный` | Полный сброс всей статистики персонала |

**Категории персонала (настраиваются ОТДЕЛЬНО):**
- 🛡️ **Персонал сервера** — хелперы, модераторы и кураторы игровых серверов
- ⚙️ **Персонал дискорда** — модераторы и администраторы Discord
- 🔨 **Билдеры** — строители карт и спавнов

**Что отслеживается:**
- 📩 **Закрытые тикеты** (за неделю и за всё время)
- 🔨 **Выданные наказания** (муты, баны, кики, варны, разбаны)
- 📋 **Проверенные заявки** (принятые и отклонённые)
- ⏱️ **Время активности** (время в голосовых каналах без AFK + текстовая активность)
- ⭐ **Баллы рейтинга** (формула активности для топа)

## 🔧 Настройка /ip (MySQL)

1. Установи: `pip install aiomysql`
2. В `cogs/admin_utils.py` заполни `MYSQL_CONFIG`
3. Раскомментируй блок с запросом
4. Адаптируй SQL-запрос под свою БД (AuthMe / CoreProtect / LiteBans / и т.д.)

## 📝 Заметки

- `data.json` создаётся автоматически и хранит: кулдауны, авто-ответы, временные баны, настройки доната/инфо, права доступа, ID ИИ-канала, **типы тикетов с формами**, **вопросы заявок**, **переопределения текстов** и привязки панелей.
- При перезапуске бота все персистентные кнопки (тикеты, заявки) продолжают работать.
- Авто-разбан проверяется каждую минуту фоновым тасом.
- Панели тикетов и заявок помнят, где установлены, и **обновляются автоматически** при изменении типов/вопросов/текстов.
- Смоук-тест без запуска бота: `python tests/test_smoke.py` (проверяет загрузку когов, команды, формы и тексты).
