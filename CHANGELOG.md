# 📝 Обновление: заявки кнопкой, до 10 вопросов, фикс data.json

## 🐛 Исправлено: `PermissionError: [Errno 13] Permission denied: 'data.json'`
- `data.json` теперь всегда ищется **рядом с файлами бота**, а не в папке,
  из которой запущен процесс (чинит ошибки при запуске через панели/сервисы
  с другой рабочей директорией и «потерю» настроек).
- Атомарная запись (временный файл + переименование) — файл не бьётся при
  падении бота посередине сохранения.
- Если файл read-only — бот пробует снять флаг сам; если прав правда нет —
  в Discord приходит понятная подсказка, а в консоль — инструкция как чинить.
- Битый JSON больше не роняет бота: оригинал уносится в `data.json.corrupt-*.bak`.
- Путь можно переопределить переменной окружения `BOT_DATA_FILE` (для тестов).

## ✨ Панель заявок как в тикетах
- На панели теперь **кнопка «📋 Подать заявку»** → эфемерное меню направлений → анкета
  (раньше список направлений висел прямо на панели).
- Текст кнопки меняется через `/тексты`: `APP_BTN_LABEL`, `APP_BTN_EMOJI`,
  подсказка меню: `APP_TYPE_SELECT_PROMPT`.
- Старые панели со списком продолжают работать; при любом изменении анкеты
  (`/заявки-настройка ...`) они автоматически обновляются до нового вида.
- Кулдаун теперь проверяется **до** открытия анкеты — игрок не заполняет поля зря.

## ✨ До 10 вопросов в анкете заявки
- `/заявки-настройка вопрос добавить` — лимит поднят с 5 до **10**.
- Лимит Discord — 5 полей в одном окне, поэтому анкеты из 6+ вопросов
  открываются **в 2 окна подряд** (ответы первой части подхватываются дальше).
- Длина ответов автоматически подгоняется под лимит embed (6000 символов).
- У тикетов лимит остался 5 (одно окно).

# 📝 Обновление: баннеры, кнопка «Передать», жалобы

## ✨ Новые возможности

### 🖼️ Баннеры внутри тикета и анкеты заявки
- У каждого типа тикета свой баннер (картинка внизу первого embed обращения):
  `/тикет-настройка баннер код ссылка` (без ссылки — убрать)
- У каждого направления заявок свой баннер внутри анкеты:
  `/заявки-настройка баннер направление ссылка`
- Как получить ссылку: отправь картинку в любой канал Discord →
  ПКМ по картинке → «Копировать ссылку» (начинается с `https://`)
- В тикете в шапке embed теперь ник + аватарка автора обращения.

### 📎 Фото/видео от игроков
Игроки кидают файлы сообщениями прямо в созданный канал тикета —
специальная функция не нужна (убрано по решению администратора).

### 🔁 Кнопка «Передать» (эскалация тикета)
- В тикете рядом с «Закрыть» появилась кнопка **«Передать тикет»**:
  пингует старшие роли и автоматически пускает их в канал с красивым embed.
- Роли: `/тикет-настройка передача добавить код @роль`
- 🔒 **«Закрыть» и «Передать» — только для персонала**: игрок НЕ может
  закрыть или передать свой тикет. Допущены: админы, `manage_channels`,
  роли пинга и роли передачи этого типа. Текст отказа: `TICKET_STAFF_ONLY`
  (настраивается через `/тексты`)
- Тексты кнопки и сообщений настраиваются из Discord:
  `/тексты изменить TICKET_FORWARD_BTN 🔁 Передать куратору`
  (ключи: `TICKET_FORWARD_BTN`, `TICKET_FORWARDED_TITLE`,
  `TICKET_FORWARDED_DESC`, `TICKET_FORWARD_OK`, `TICKET_STAFF_ONLY`...)

### 🚨 Новые типы тикетов «Жалобы» (добавляются автоматически)
- **🚨 Жалоба на игрока** — каналы `report-player-ник`,
  вопросы: ник нарушителя / описание / доказательства
- **🛡️ Жалоба на персонал** — каналы `report-staff-ник`,
  вопросы: ник/ID сотрудника / что произошло
- ⚠️ **Заполнить в `config.py`**:
  `REPORT_PLAYER_PING_ROLES` и `REPORT_STAFF_PING_ROLES` (пинги),
  `REPORT_*_ESCALATE_ROLES` (кому передавать по кнопке)
- Добавляются одноразово при запуске; если удалить через
  `/тикет-настройка удалить` — назад не вернётся

### ✉️ ЛС игроку при решении заявки
- И при принятии, и при отклонении игрок получает ЛС от бота.
- Тексты настраиваются: `/тексты изменить APP_ACCEPTED_DM_DESC ...`,
  `APP_ACCEPTED_DM_TITLE ...`, `APP_REJECTED_DM_DESC ...` и т.д.
- Доступны плейсхолдеры: `{guild}` — сервер, `{type}` — направление заявки.

## 🛠️ Технические изменения
- `cogs/tickets.py`: надёжное закрытие тикета — ЛС/логи/транскрипт/статистика
  выполняются в защищённых шагах, а канал удаляется **в любом случае**;
  если удалить не выходит (нет права «Управление каналами» или другой сбой) —
  бот прямо говорит причину вместо тихого зависания на «🔄 Генерирую транскрипт...»
- `cogs/tickets.py`: `TicketCloseView` → `TicketControlView`
  (кнопки «Закрыть» + «Передать»), баннер, аватар автора обращения
- `cogs/tickets.py`: контроль прав на закрытие и передачу — игрок не может
  закрыть/передать свой тикет (проверка и в кнопке, и в форме)
- `cogs/applications.py`: баннер анкеты, плейсхолдер `{type}` в ЛС
- `utils/forms.py`: поля типов `banner`, `escalate_roles`;
  готовые типы жалоб + одноразовая миграция; хранилище `app_settings` (баннеры)
- `cogs/forms_setup.py`: новые команды `баннер`, группа `передача`
- `config.py`: роли жалоб/передачи
- `texts.py`: новые настраиваемые тексты (все через `/тексты`)
- `tests/test_smoke.py`: покрытие новых систем (25 проверок)
